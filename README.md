# Task 1: Basic Network Scanning with Nmap

## Objective
Use Nmap to scan a local machine, identify open ports and services, and understand potential network security risks.

## Tools Used
- macOS
- Nmap 7.99.3
- Terminal

## What is Nmap?
Nmap (Network Mapper) is a network scanning tool used to discover hosts, open ports, and services running on a system.

## Installation
Nmap was installed using Homebrew:

```bash
brew install nmap



nmap -sV 127.0.0.1


nmap -sV -p 5000,7000 127.0.0.1


Reply `d` when finished.
