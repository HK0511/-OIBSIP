Task 4 – Common Network Security Threats

Internship

Oasis Infobyte – Security Analyst Internship

Objective

The objective of this project is to study common network security threats, understand how cyberattacks work, and identify methods to prevent them.

Topics Covered

1. Denial of Service (DoS) and Distributed Denial of Service (DDoS)

* Meaning and working of DoS and DDoS attacks.
* Real-world example: Mirai botnet attack.
* Impact on network availability.
* Prevention methods and security measures.

2. Man-in-the-Middle (MITM) Attack

* How attackers intercept communication.
* Public Wi-Fi security risks.
* Possible data theft and privacy impacts.
* Prevention using HTTPS, encryption, and secure networks.

3. IP Spoofing

* Meaning of IP address spoofing.
* How attackers forge source IP addresses.
* Security risks and possible attacks.
* Prevention using packet filtering and network security controls.

4. DNS Poisoning

* How attackers manipulate DNS information.
* Risks of redirecting users to fraudulent websites.
* Real-world examples and impacts.
* Prevention using DNSSEC and secure DNS practices.

Comparison

The report includes a comparison of these threats based on attack methods, affected systems, difficulty, and mitigation techniques.

Conclusion

This research highlights the importance of:

1. Strong network security controls.
2. Monitoring suspicious network activity.
3. Using encryption and secure communication protocols.
